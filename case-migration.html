Case Study 01 — Meta / Accounts Center

Global identity migration

From multiple linked accounts to one account with multiple profiles — shipped without breaking the thing people trust most.

Context

Technical Program Manager at Meta since May 2021, working on Accounts Center and Settings. The migration spanned 4 organizations and 11 workstreams.

Problem

Identity was fragmented across apps: people held multiple linked accounts, and every change touched many teams at once. A migration at this scale fails loudly if any one team blocks it — so the program had to be built so that no single-team dependency could block the release.

Solution

Alex served as partner point-of-contact, created the staged rollout plan, and ran central launch command — war-room operations, preemptive incident mitigation, and on-call layering across the workstreams — so the migration moved in controlled stages with risks caught before they became incidents.

Wins

Shipped with top-tier metrics neutral and zero rollbacks — the migration landed, and the experience people relied on stayed intact.
